# layout-matching

Method used by the Layout agent. _Source: Part 3, Skill 1._

## What it's for

Study all the club's slide templates and sample decks, then design each slide as a fresh, creative layout in the template's style that passes the template rules and presents the outline content clearly.

## Rules

1. **Study first.** Read the club PowerPoint template, the design-rules file, and the sample/reference decks to learn the club's visual language before laying out a slide.
   _(Layout agent input: Part 4.)_
2. **Fresh each run.** Each run produces a new, visibly different layout; no two runs with the same input give the same arrangement.
3. **Template fonts/colors only.** Every text box uses only the club template's fonts and colors.
   _(Quality standard 1.)_
4. **Clean arrangement.** No overlapping boxes, misaligned columns, or clip art.
   _(Quality standard 3.)_
5. **Main point first, template style.** Arrange boxes so the arrangement puts the outline's main point first, is easy to read, and looks similar in style to the template rather than generic.
6. **Leave boxes empty.** Leave each box empty of text at layout time; the Fill agent adds outline text afterward.
