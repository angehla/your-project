# point-mapping

Method used by the Fill agent. _Source: Part 3, Skill 2._

## What it's for

Put each outline point into exactly one box and transcribe it line-for-line, adding no filler.

## Rules

1. **One point per box.** Put exactly one point from the outline in each box; no point in more than one box.
   _(Quality standard 5.)_
2. **Transcribe as-is.** Copy each outline line as-is; do not paraphrase, add, or remove words.
   _(Quality standard 4.)_
3. **Only the Layout agent's boxes.** Use only the boxes the Layout agent set up; do not create or merge boxes.
4. **Never change the message or framing.** Never change what the outline says or how a point is framed (e.g. example vs recommendation).
   _(Human decision 1, Part 7.)_

## Sources

Quality standards 4 and 5; Human decision 1; Research log 3.
